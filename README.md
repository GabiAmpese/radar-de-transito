# 🚦Radar de Trânsito
## Resumo para Estudo

🔹 void main() { }
É onde o programa começa a funcionar.

🔹 Variáveis double
É um tipo de variável usado para números com casas decimais. 

🔹 IO.readln()
Sempre retorna um texto (String).

🔹 Double.parseDouble()
Converte valores do tipo String para double, permitindo cálculos matemáticos.

🔹 IO.println()
Serve para mostrar mensagem na tela.

🔹 Estrutura if / else if / else
É usada para tomar decisões no código.
Como funciona:
if → primeira condição
else if → outra condição, se a primeira for falsa
else → se nenhuma das anteriores for verdadeira
